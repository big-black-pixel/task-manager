/* --- БАЗОВАЯ РАСКЛАДКА БЛОКОВ --- */

display: block;        /* - блочный режим: элемент занимает всю доступную ширину и начинается с новой строки */
display: inline;       /* - строчный режим: элемент стоит внутри строки текста, width/height обычно не работают как у блока */

display: flex;         /* - включает flexbox: родитель становится flex-контейнером и управляет детьми по одной оси */

top: 0;             /* - смещает элемент сверху; работает вместе с position */
